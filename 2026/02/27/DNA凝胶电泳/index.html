DNA琼脂糖凝胶电泳

一、实验材料与试剂

  • 凝胶制备：
    • 琼脂糖
    • 电泳缓冲液（TAE 或 TBE，通常配制为 50× 储备液，使用时稀释为 1×）
    • 锥形瓶（用于加热溶解琼脂糖）
    • 制胶模具（胶槽）
    • 梳子（根据样品孔数选择）
  • 样品与上样：
    • DNA样品（PCR产物、酶切产物、质粒等）
    • DNA上样缓冲液（6× 或 10×，含溴酚蓝、二甲苯青、甘油）
    • DNA分子量标准（DNA Marker / Ladder）
  • 染色与观察：
    • 核酸染料（如GelRed、GoldView、EB等）
    • 紫外透射仪或凝胶成像系统
  • 电泳装置：
    • 水平电泳槽
    • 电源供应器
  • 耗材：
    • 移液器及枪头
    • 微量离心管
    • 手套
    • 保鲜膜（覆盖凝胶用）

二、实验前准备

  1. 缓冲液配制：检查或配制足量 1× 电泳缓冲液（TAE或TBE），用于制胶和电泳。
  2. 模具准备：洗净并干燥制胶槽和梳子，水平放置。
  3. 样品准备：DNA样品置于冰上，上样缓冲液室温融化。
  4. 染料准备：若使用EB等致癌染料，需在专门区域操作并做好防护。

三、核心操作步骤

  1. 制备琼脂糖凝胶

    • 根据DNA片段大小确定凝胶浓度（常用0.8%-2%）：
      • 0.8%：分离大片段DNA（5-10 kb）
      • 1.0%-1.2%：常规分离（0.5-7 kb）
      • 1.5%-2.0%：分离小片段（0.1-2 kb）
    • 称取适量琼脂糖，加入锥形瓶中，加入适量1×电泳缓冲液。
    • 微波炉加热至沸腾，使琼脂糖完全溶解（溶液清亮无颗粒）。加热过程中摇晃1-2次，防止暴沸。
    • 关键操作：溶液冷却至约50-60℃（手背触碰瓶身不烫手），加入核酸染料（如GelRed 1:10,000稀释），轻轻摇晃混匀，避免产生气泡。

  2. 灌制凝胶

    • 将梳子插入制胶槽的适当位置。
    • 缓慢将琼脂糖溶液倒入制胶槽，厚度约3-5 mm。
    • 用枪头挑去表面气泡。
    • 室温静置20-30分钟，直至凝胶完全凝固（凝胶呈乳白色不透明）。

  3. 安装凝胶与加样

    • 小心拔出梳子，保持孔道完整。
    • 将凝胶连同胶槽放入电泳槽，加样孔朝向负极（黑色电极）。
    • 倒入1×电泳缓冲液，液面高出凝胶表面约1-2 mm。
    • 在封口膜或微量离心管中混合DNA样品和上样缓冲液：
      • 5 μL DNA样品 + 1 μL 6×上样缓冲液（或按比例混合）。
    • 用移液器吸取混合液，垂直对准加样孔，缓慢推入孔中。
    • 关键操作：加样时避免刺破凝胶孔底，避免样品溢出孔外。记录加样顺序和上样量。
    • 在适当孔中加入DNA Marker（如5 μL）。

  4. 电泳

    • 盖上电泳槽盖，连接电源（注意正负极：DNA带负电荷，向正极移动）。
    • 设置电压：通常为5-10 V/cm（电极间距离），例如凝胶长度10 cm，可设置50-100 V。
    • 启动电泳，观察溴酚蓝（蓝色）和二甲苯青（蓝绿色）指示剂的迁移情况。
    • 电泳至溴酚蓝迁移至凝胶约2/3-3/4处时停止（约30-60分钟，依电压和凝胶浓度而定）。

  5. 凝胶成像与结果记录

    • 关闭电源，取出凝胶（戴手套操作，若使用EB需格外小心）。
    • 将凝胶放入凝胶成像仪中，或在紫外透射仪上观察。
    • 调整焦距和曝光，拍摄图像。
    • 保存图像文件，标注Marker条带大小和样品信息。

四、实验后处理

  1. 废弃物处理：
    • 含EB等染料的凝胶需放入专用废弃物容器，按实验室规定处理（不可随意丢弃）。
    • 接触过EB的枪头、手套等同样放入专用垃圾袋。
  2. 电泳槽清洗：倒掉缓冲液，用自来水冲洗电泳槽和制胶模具，再用去离子水漂洗，晾干。
  3. 数据备份：保存电泳图像，记录实验条件和结果。

五、关键注意事项

  1. 安全防护：

    • EB为强致癌物，操作时必须戴双层手套，在指定区域进行。尽量使用低毒/无毒的替代染料（如GelRed）。
    • 紫外光对眼睛和皮肤有害，观察凝胶时务必佩戴紫外防护面罩或护目镜。

  2. 凝胶制备要点：

    • 琼脂糖需彻底溶解，否则凝胶不均匀，影响条带分离。
    • 灌胶时温度不宜过高，以免凝胶变形或损伤梳子；但也不宜过低，否则提前凝固。
    • 梳子插入深度：梳齿底部距胶槽底部约0.5-1 mm，确保形成完整孔底。

  3. 电泳要点：

    • 电压过高会导致凝胶发热、条带弥散，低电压过夜可提高分辨率。
    • 缓冲液需覆盖凝胶，防止电泳时凝胶干涸。
    • 确保加样孔无气泡或破碎，否则样品无法正常进入凝胶。

  4. 结果判断：

    • Marker条带应清晰，用于估算样品片段大小。
    • 若出现拖尾，可能原因：样品降解、上样量过大、电压过高、缓冲液失效。
    • 若出现条带模糊，可能原因：凝胶浓度不合适、电泳时间过长、凝胶有气泡。

六、补充说明

  • 缓冲液选择：TAE缓冲能力强，适合分离大片段和回收DNA；TBE缓冲容量高，分辨率稍高，但可能影响DNA回收效率（硼酸抑制某些酶）。
  • 脉冲场电泳：分离超大片段DNA（>20 kb）需使用脉冲场电泳，本SOP不适用。
  • 染色方法：除胶内预染外，也可电泳后用染色液浸泡染色（适用于对染料敏感的实验）。
  • 应用场景：DNA凝胶电泳可用于PCR产物鉴定、酶切产物分析、质粒检测、DNA片段回收前确认等。
  • 回收用途：若需从凝胶中回收DNA，需使用长波紫外光（365 nm）并快速操作，减少UV损伤，并使用无EB污染的凝胶和缓冲液。
