学习通作业爬取

1. 简介

基于 Selenium 自动化浏览器，可批量爬取超星学习通（chaoxing）指定课程的所有作业内容（包括题目和题干），并保存为本地文本文件。

主要功能：

  • 自动登录（支持账号密码自动填写或手动扫码）
  • 选择指定课程并进入“作业”模块
  • 遍历所有作业列表，翻页抓取每份作业的标题和详细内容
  • 结果保存为以课程名命名的 .txt 文件

2. 环境准备

2.1 安装 Python

确保你的计算机已安装 Python 3.7 及以上版本。可以从 python.org 下载安装。

2.2 安装依赖库

在终端（命令提示符）中执行以下命令：

  • selenium：浏览器自动化框架

2.3 浏览器要求

  • 本脚本默认使用 Microsoft Edge 浏览器。请确保 Edge 已更新到最新版本。
  • 若想使用 Chrome，可修改脚本中对应的驱动管理器和选项，但本文档以 Edge 为例。

3. 脚本配置

如何获取课程图标的 XPath？

  1. 在浏览器中登录学习通，进入课程列表页面。
  2. 右键点击你想要爬取的课程图标（或课程名称区域），选择“检查”。
  3. 在开发者工具中，找到对应元素的 HTML 代码，右键 → 复制 → 复制 XPath。
  4. 将复制的 XPath 粘贴给 lesson_Xpath 变量。

注意：XPath 可能会随网站改版而变化，若脚本失效请重新获取。

脚本提供了两种登录方式，默认使用自动填密码登录。你可以根据需要选择：

方式二：手动扫码登录

若不想在脚本中保存密码，可以改为手动扫码：

  1. 注释掉自动填密码的 send_keys 行。
  2. 取消注释 # sleep(50) 和 #预留扫码登录时间 之间的代码，并调整等待时间（如 sleep(30) 等待扫码）。
  3. 确保脚本在扫码期间不会自动关闭。

注意：无论哪种方式，登录后都需要处理 iframe 切换，脚本已包含相关代码。

4.2 运行过程说明

  1. 浏览器自动打开学习通登录页面。
  2. 根据配置自动填写账号密码并提交，或等待你扫码。
  3. 登录成功后，进入课程列表页面，根据 lesson_Xpath 点击指定课程。
  4. 在新标签页中点击“作业”按钮。
  5. 进入作业列表页（嵌套在 iframe 中），脚本会自动计算总页数并逐页抓取。
  6. 每份作业会打开新标签页，提取标题和内容，保存到文本文件，然后关闭标签页返回列表。
  7. 全部抓取完成后，浏览器关闭，并输出总用时。

5. 注意事项

5.1 元素定位失效

学习通页面结构可能更新，导致 XPath 失效。若脚本报错“找不到元素”，请重新获取以下关键位置的 XPath：

  • 登录页面的手机号输入框、密码输入框、登录按钮
  • 课程列表页的课程图标
  • 作业按钮
  • 作业列表的 iframe
  • 分页控件
  • 作业详情页的标题和内容区域

可使用浏览器的“检查”功能，找到元素后右键复制 XPath，并替换脚本中对应的 XPath。

5.2 等待时间与网络延迟

脚本使用了 implicitly_wait(3) 和部分 sleep，若你的网络较慢，可适当增加等待时间（例如将 sleep(3) 改为 sleep(5)）。也可改用 WebDriverWait 显式等待提高稳定性。

5.3 登录凭证安全

若选择自动填密码，脚本中会明文保存账号密码。请确保脚本文件不泄露给他人。建议使用完毕后及时删除敏感信息。

5.4 反爬机制

学习通可能有反自动化检测。脚本中添加了 excludeSwitches 选项，可隐藏自动化特征。如果仍然被检测，可以尝试：

  • 降低操作速度（增加 sleep 时间）
  • 使用 undetected-chromedriver 等更隐蔽的方式
  • 避免频繁运行，模拟人工操作间隔

5.5 仅限个人学习使用

本脚本仅供个人学习、备份作业使用，请勿用于商业或非法用途。请遵守学习通平台的使用条款，避免对服务器造成过大压力。

6. 常见问题及解决

Q1: 运行后浏览器一闪而过，没有执行操作？

  • 检查 option.headless = False 是否设置，若为 True 则浏览器在后台运行，可以改为 False 观察。
  • 检查 webdriver-manager 是否正确安装，驱动是否下载成功。

Q2: 提示“找不到元素”错误？

  • 确认登录成功：有时登录页面会有验证码或滑块验证，脚本无法处理。可尝试手动扫码登录。
  • 确认 XPath 是否正确，尤其是课程图标 XPath 是否复制准确。
  • 确认 iframe 切换：某些元素位于 iframe 内，需要先 switch_to.frame。

Q3: 作业列表翻页失败？

  • 检查分页控件的 XPath '//*[@id="page"]/ul/li[4]/i' 是否仍然有效。若失效，请重新获取“下一页”按钮的 XPath。
  • 脚本中翻页点击的是第 4 个列表项（索引从1开始），可能不是所有课程都相同，需根据实际分页结构调整。

Q4: 抓取的内容为空或不完整？

  • 可能是页面加载延迟导致内容未完全渲染。可在点击作业后增加 sleep 或使用显式等待等待某个元素出现。
  • 检查作业详情页的 XPath 是否正确，例如 questions_name 和 questions 的定位。

Q5: 如何只抓取部分作业？

  • 可以修改循环范围，例如只抓取前几页，或根据作业标题判断。

7. 结语

本脚本提供了一种自动化爬取学习通作业的思路，可大幅减少手动复制粘贴的繁琐工作。但由于网站更新频繁，脚本可能需要定期维护。如果你在使用中遇到问题，可以根据错误信息调整 XPath 或等待策略。

祝使用愉快！
