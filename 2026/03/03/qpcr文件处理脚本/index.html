qPCR数据分析脚本使用教程

本教程介绍如何使用Python脚本自动处理Bio-Rad CFX导出的qPCR数据，计算基因相对表达量（ΔΔCt法），并对结果进行格式化和可视化。

脚本功能概述

  • 读取Bio-Rad CFX导出的Excel文件（包含“Content”、“Target”、“Cq”等列）
  • 自动识别除内参基因（GAPDH）外的所有目的基因
  • 计算每个样本的ΔCt、平均ΔCt、ΔΔCt、2^(-ΔΔCt)及平均值
  • 选取对照组样本的ΔCt中位数作为校准值
  • 计算每个样本目的基因和内参的复孔标准差（STD），并标记误差较大的数据（默认阈值0.2）
  • 生成格式化Excel结果文件，包含每个基因的计算表格，并标注对照组样本（蓝色）和高误差数据（红色）
  • 自动生成每个基因的相对表达量柱状图（对照组 vs 实验组，含误差棒），并保存在plots文件夹中
  • 在Excel中新增“plots”工作表，插入生成的图片

环境要求

  • Python 3.6+
  • 依赖库：pandas, numpy, openpyxl, matplotlib, datetime, os
  • 安装命令：pip install pandas numpy openpyxl matplotlib

使用前准备

1. 数据文件准备

从Bio-Rad CFX仪器导出qPCR数据（通常为Excel格式），确保文件中包含以下关键列：

  • Content：样本名称（需手动编号或标注）
  • Target：基因名称（如GAPDH、目标基因）
  • Cq：Ct值

重要操作：

  • 在Bio-Rad CFX软件中编辑反应板，为每个样本的“Content”列填写准确的样本名称（例如：C1、C2、T1、T2等）。
  • 确保内参基因命名为“GAPDH”（脚本默认以此识别内参）。
  • 对复孔进行编号（同一Content名称下包含多个复孔，脚本会自动按Content分组计算平均值）。
  • 务必手动保存Excel文件（Ctrl+S），否则脚本可能无法识别文件内容。

2. 确定对照组样本个数

脚本需要知道对照组样本的数量（例如C1、C2两个对照，则数量为2）。对照组样本应连续排列在文件的前几行（按Content排序后），脚本默认前N个Content为对照组。

输出结果说明

1. 生成文件夹

在原始数据文件所在目录下，会自动创建两个文件夹：

  • output：存放处理后的Excel结果文件，命名格式为 YYYYMMDDHHMM_实验材料名称_基因列表.xlsx
  • plots：存放生成的柱状图，子文件夹以 当前日期时间_实验材料名称 命名，每张图片命名为 实验材料名称_基因名.png

2. Excel结果文件详解

打开output文件夹中的Excel文件，你会看到：

  • 工作表 genes：包含所有基因的计算结果，每个基因的数据从上到下依次排列，基因之间空一行。
  • 工作表 plots：自动插入的柱状图图片。

genes工作表各列含义（从左到右）：

列 名称 说明
A Sample 样本名称（Content）
B 目的基因名 该基因每个复孔的Ct值
C STD1 目的基因复孔标准差（隐藏列，用于误差判断）
D GAPDH 内参基因每个复孔的Ct值
E STD2 内参基因复孔标准差（隐藏列）
F ΔCt 目的基因Ct - 内参Ct
G Average ΔCT 同一样本ΔCt的平均值（仅显示第一行，后续重复值显示为空）
H ΔΔCt 每个复孔的ΔCt减去对照组ΔCt中位数
I Average ΔΔCt 同一样本ΔΔCt的平均值（仅显示第一行）
J 2^(-ΔΔCT) 相对表达量（每个复孔）
K Average 2^(-ΔΔCT) 同一样本相对表达量的平均值（仅显示第一行）
L ttest 预留列，暂未实现t检验

颜色标注说明：

  • 蓝色：用于计算ΔΔCt的对照组样本（即ΔCt中位数所在的行），其“Average ΔCT”和对应的“Sample”单元格被标蓝。
  • 红色：当STD1或STD2 > 0.2时，该基因对应的目的基因列、GAPDH列以及最终的平均相对表达量列（Average 2^(-ΔΔCT)）均标红，提示该样本复孔间误差较大。

3. 柱状图说明

在plots文件夹中，每个基因生成一张柱状图：

  • 横轴：Ctrl（对照组）、EG（实验组）
  • 纵轴：相对表达量（目的基因/GAPDH），数值为2^(-ΔΔCt)的平均值
  • 误差棒：对应组的标准差（STD）
  • 图片命名：实验材料名称_基因名.png

常见问题与注意事项

  1. 必须手动保存Excel文件：从CFX导出后，即使未做任何修改，也需在Excel中打开并保存一次（Ctrl+S），否则脚本可能无法读取文件内容。
  2. Content列编号：确保同一Content名称对应同一组复孔，且对照组样本名称一致（如C1、C2…），以便脚本正确分组。
  3. 对照组顺序：脚本默认按Content排序后，前N个Content为对照组，请确保对照组在文件中连续排列在前。
  4. 标准差阈值：脚本默认使用0.2作为复孔误差的容忍上限，如需调整，可修改脚本中 threshold = 0.2 的值。
  5. 基因名称：脚本自动识别除“GAPDH”以外的所有Target作为目的基因，请确保内参基因命名为“GAPDH”。
  6. 文件路径格式：建议使用原始字符串（r"..."）或双反斜杠（\\）避免转义错误。

脚本自定义修改

  • 更改内参基因名称：如果内参不是GAPDH，请将脚本中所有“GAPDH”替换为实际名称。
  • 更改误差判断列：脚本默认检查C列（STD1）和E列（STD2），若隐藏列位置变化，需相应调整 highlight_adjacent_cells('C', threshold) 中的列字母。
  • 添加t检验：可在脚本中增加统计计算，并将结果填入L列。
